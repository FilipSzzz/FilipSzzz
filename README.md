## 🚀 Featured project — [LLM Security Gateway](https://github.com/FilipSzzz/LLM_Security_Gateway)

A **FastAPI proxy** that sits between an application and LLM APIs and inspects the traffic in both directions.

- 🛡️ **Prompt-injection detection** — blocks malicious instructions before they reach the model
- 🕵️ **PII masking** — strips personal data from prompts and responses
- ⏱️ **Rate limiting** — protects the API from abuse
- 🐳 **Dockerized** — runs locally with a single `docker compose up`

🚧 *In active development — feedback and issues welcome.*
